# CC:RJ45

![Banner](https://cdn.modrinth.com/data/GZ875jdx/images/25d9b4fe2e09119f988a66e0e000b5345c05f950.jpeg)

This mod adds hanging wires for _CC:Tweaked_. With compats for _Create Aeronautics_ mod.

## Blocks & Items

>  **Net Cable Connector** - Connects to any solid surface. Up to 2 links per connector. Acts as a standard CC:Tweaked wired network endpoint.

>  **Net Cable Hub** - Same form factor, 4 links. Lets you build star topologies without chaining blocks.

>  **Huge Net Cable Connector** - A larger variant with thicker cables. Supports up to 2 links with an extended range.

>  **Net Connector Cable** - The linking item. Right-click two connectors to create a cable link. Sneak + right-click to break a link. _Can be dyed in any vanilla color._

> **Portable Drive** - A portable hard drive for CC:Tweaked computers. Works in any disk drive. Crafted with terracotta and amethyst. _Can be dyed in any color._
